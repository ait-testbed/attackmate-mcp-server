# Contributing

## Developer setup

If you plan to contribute to the development of this package, follow these steps to set up
the dev environment and install pre-commit hooks (using [prek](https://github.com/j178/prek)):

```bash
uv sync
prek install
```

## Running tests

```bash
uv run pytest
```

## Pull requests

See `.github/pull_request_template.md` for the checklist applied to every PR.
